AuD Code Tester

Hier kannst Du Deinen Code zur automatischen Überprüfung einreichen, um zu testen, ob Dein Code bei der Abgabe über StudOn erfolgreich kompiliert und ausgeführt wird.
Diese Website ist nicht 100% verlässlich. Bitte achte auch bei erfolgreicher Überprüfung auf die Einhaltung der Vorgaben im StudOn Kurs. Vor allem falsche Dateinamen, Encodings und Methodennamen, sowie Parameteranzahl, führen oft zu Compile Errors und damit 0 Punkten bei der Abgabe über StudOn.
Bei Fragen und Problemen bitte im Forum melden.

Wichtiger Hinweis: Du musst trotzdem Deinen Code in StudOn einreichen, diese Website ist regelrecht nur ein Hilfsmittel.

📁 Java-Dateien auswählen...
Wähle eine oder mehrere .java-Dateien aus. Halte Strg/Cmd gedrückt, um mehrere Dateien auszuwählen.
